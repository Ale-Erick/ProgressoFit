# ProgressoFit

Sistema web para acompanhamento da evolução física de praticantes de musculação,
com registro de métricas corporais, treinos e planos alimentares revisados por
profissionais habilitados.

## Equipe
- Alejandro (alejandro.messias@escolar.ifrn.edu.br)
- Erick (douglas.erick@escolar.ifrn.edu.br)

## Tecnologias
Python 3, Django, SQLite, HTML5, CSS3, JavaScript, Bootstrap

## O que já funciona (Etapa 1)
- Navegação entre as telas: home, login, cadastro, perfil, verificação de especialista,
  registrar métrica, evolução, detalhe da métrica, treinos, nutrição e painel do especialista
- Models: Perfil, Especialista, MetricaCorporal, Treino e PlanoAlimentar
- Cadastro dos dados pelo Django Admin
- Listagens e detalhe lendo do banco de dados
